# 개인정보 및 데이터 처리 안내

Repo Aquarium은 별도 서비스 운영이나 사용자 추적 없이 실행되도록 설계되었습니다.

## 읽는 데이터

Action 또는 CLI는 장면 생성에 필요한 GitHub 저장소 데이터만 요청합니다. 저장소 기본 정보, 최근 커밋과 기여자, 언어 사용량, 최신 릴리스, 그리고 설정한 경우 기본 브랜치에서 특정 워크플로의 최신 실행 상태를 읽습니다.

## 데이터가 이동하는 곳

- 요청은 GitHub Actions 러너 또는 사용자의 컴퓨터에서 GitHub API로 직접 전송됩니다.
- 생성된 SVG와 JSON만 설정한 브랜치 또는 로컬 출력 경로에 기록됩니다.
- 분석 서버, 텔레메트리 SDK, 데이터베이스, 호스팅 백엔드, 광고 연동, 사용자 계정 시스템이 없습니다.
- 저장소 데이터와 토큰을 프로젝트 관리자나 다른 제3자에게 보내지 않습니다.

## 토큰

`GITHUB_TOKEN`은 실행 중 GitHub API 호출에만 사용되며 생성된 SVG나 JSON에 기록되지 않습니다. 로그 또는 파일에 토큰을 저장하지 않습니다. GitHub Actions에서는 `contents: write`만 부여하고, `ci-workflow`를 사용할 때만 `actions: read`를 추가하는 것을 권장합니다.

## 공개되는 정보

생성된 `summary.json`과 수족관에는 저장소 통계가 반영됩니다. 공개 저장소에서는 결과 브랜치의 생성 파일도 공개됩니다. 비공개 또는 민감한 프로젝트에 적용하기 전 저장소 공개 범위와 결과 브랜치를 확인하세요.
